1. Architecture Overview

This reference documents the AWS infrastructure for a 3-node OKD compact cluster. All three nodes act as both control-plane and workers (no dedicated worker pool), reducing cost while maintaining full etcd quorum. GitOps is managed via ArgoCD connected to a GitHub repository.

ℹ️
Port 22623 is the Machine Config Server (MCS) — it serves ignition configs to nodes during boot. It must only be accessible internally from within the VPC.

RoleAttached ToKey Permissions

Security note: The installer IAM user/role requires broad permissions during provisioning. Remove or restrict it after the cluster is running.

10. Install Flow

  • 1
    Terraform — Core Infrastructure
    Provision VPC, subnets, IGW, NAT GWs, route tables, security groups, IAM roles, NLBs, Route53 zones + records, S3 buckets.
  • 2
    Generate Ignition Configs
    Run openshift-install create install-config, customize install-config.yaml for compact topology (3 replicas, 0 workers), then run openshift-install create ignition-configs.
  • 3
    Upload Bootstrap Ignition
    Upload bootstrap.ign to the S3 bootstrap bucket. Master ignition files reference the MCS for their own configs.
  • 4
    Terraform — Bootstrap + Master EC2
    Launch the temporary bootstrap node and all 3 master nodes using the ignition configs as EC2 user-data.
  • 5
    Bootstrap Process (~30–45 min)
    Bootstrap node starts a temporary control plane. Master nodes boot, pull their ignition configs from MCS, join etcd quorum, and take over as permanent control plane. Bootstrap node is then terminated.
  • 6
    Cluster Operators Stabilize
    Run openshift-install wait-for install-complete. All cluster operators (console, image-registry, ingress, etc.) become available.
  • 7
    Post-Install: ArgoCD + GitOps
    Install the OpenShift GitOps Operator via OperatorHub. Connect your GitHub repo. Deploy the app-of-apps ArgoCD Application.

Key CLI Commands

# Download OKD installer
wget https://github.com/okd-project/okd/releases/download/<version>/openshift-install-linux.tar.gz
tar -xzf openshift-install-linux.tar.gz

# Create install config
./openshift-install create install-config --dir=./cluster-config

# Generate ignition configs
./openshift-install create ignition-configs --dir=./cluster-config

# Monitor bootstrap
./openshift-install wait-for bootstrap-complete --dir=./cluster-config --log-level=info

# Monitor install completion
./openshift-install wait-for install-complete --dir=./cluster-config --log-level=info

# Access cluster
export KUBECONFIG=./cluster-config/auth/kubeconfig
oc get nodes
oc get clusteroperators

install-config.yaml (compact topology)

apiVersion: v1
baseDomain: example.com
metadata:
  name: okd-prod
compute:
  - name: worker
    replicas: 0            # Compact: no dedicated workers
controlPlane:
  name: master
  replicas: 3
  platform:
    aws:
      type: m5.2xlarge
      zones:
        - us-east-1a
        - us-east-1b
        - us-east-1c
platform:
  aws:
    region: us-east-1
pullSecret: '{"auths": ...}'   # Use fake pull secret for OKD
sshKey: |
  ssh-rsa AAAA...              # Your public SSH key
ℹ️
OKD does not require a Red Hat pull secret. Use the fake pull secret from the OKD documentation or leave it as {"auths":{"fake":{"auth":"aWQ6cGFzcwo="}}}.

11. GitOps & ArgoCD

Install OpenShift GitOps Operator

# Via CLI (or use OperatorHub web console)
oc apply -f - <<EOF
apiVersion: operators.coreos.com/v1alpha1
kind: Subscription
metadata:
  name: openshift-gitops-operator
  namespace: openshift-operators
spec:
  channel: latest
  name: openshift-gitops-operator
  source: community-operators
  sourceNamespace: openshift-marketplace
EOF

# Get ArgoCD admin password
oc extract secret/openshift-gitops-cluster \
  -n openshift-gitops --to=-

App-of-Apps Pattern

# gitops/apps/app-of-apps.yaml
apiVersion: argoproj.io/v1alpha1
kind: Application
metadata:
  name: app-of-apps
  namespace: openshift-gitops
spec:
  project: default
  source:
    repoURL: https://github.com/4mcqueens/OKD-lab
    targetRevision: main
    path: gitops/apps
  destination:
    server: https://kubernetes.default.svc
    namespace: openshift-gitops
  syncPolicy:
    automated:
      prune: true
      selfHeal: true

12. Terraform Structure

terraform/
├── main.tf                          # Root module — calls all child modules
├── variables.tf                     # Input variables
├── outputs.tf                       # Output values
├── versions.tf                      # Required providers + versions
├── modules/
│   ├── vpc/                         # VPC, subnets, IGW, NAT GWs, route tables
│   ├── security-groups/             # All security group definitions
│   ├── iam/                         # IAM roles, policies, instance profiles
│   ├── load-balancers/              # NLBs + target groups + listeners
│   ├── dns/                         # Route53 public + private zones + records
│   ├── s3/                          # Bootstrap + image registry buckets
│   └── ec2/                         # Bootstrap node + master nodes
└── environments/
    └── okd-prod/
        ├── main.tf                  # Environment-specific root
        ├── terraform.tfvars         # Env variable values
        └── backend.tf               # S3 remote state config
